==============================
CS50 Python — Week 00 NOTES
==============================

🔹 HOW IT WORKS (Big Picture)
- Python code is just TEXT saved in .py files
- Code is executed by the Python INTERPRETER
- Program runs top → bottom, left → right
- Run programs via terminal:
  python filename.py
- Errors = bugs (normal, expected, part of learning)

------------------------------
🔹 FIRST PROGRAM
------------------------------
print("hello, world")

- print() → built-in function
- "hello, world" → STRING (text)
- Output on screen = SIDE EFFECT
- Quotes mean literal text

------------------------------
🔹 FUNCTIONS (built-in)
------------------------------
Functions = actions / verbs

Examples:
- print() → shows output
- input() → gets user input
- int() → converts to integer
- float() → converts to decimal number
- round() → rounds numbers

Functions:
- can take ARGUMENTS
- can RETURN values
- can have SIDE EFFECTS (like printing)

------------------------------
🔹 VARIABLES
------------------------------
Variable = container for a value in memory

Example:
name = input("What's your name? ")

- "=" means ASSIGNMENT (right → left)
- NOT math equality
- name stores the RETURN value of input()

------------------------------
🔹 STRINGS (str)
------------------------------
- Text data type
- Created with " " or ' '

Common string methods (dot-syntax):
- name.strip()     → removes spaces (left & right)
- name.capitalize()→ capitalizes first letter
- name.title()     → capitalizes each word
- name.split(" ")  → splits string into parts

Methods:
- Belong to the object
- Use DOT syntax:
  variable.method()

Example:
name = name.strip().title()

------------------------------
🔹 PRINT — IMPORTANT DETAILS
------------------------------
print("Hello", name)

- Multiple arguments separated by commas
- Automatically adds SPACE between arguments
- Automatically ends with NEW LINE

Named parameters:
- sep=" "  → separator between arguments
- end="\n" → what comes at the end

Example:
print("Hello", end="")
print(name)

------------------------------
🔹 STRING CONCATENATION
------------------------------
Using +
"Hello, " + name

- + joins strings (NOT math)
- Called concatenation

------------------------------
🔹 F-STRINGS (FORMAT STRINGS)
------------------------------
f"Hello, {name}"

- Put f before quotes
- {} inserts variable values
- Cleanest & preferred style

Formatting numbers:
f"{z:,}"    → adds commas (1,000)
f"{z:.2f}"  → 2 decimal places

------------------------------
🔹 COMMENTS & PSEUDOCODE
------------------------------
# This is a comment

- Ignored by Python
- Used to explain intent
- Helps debugging & readability

Pseudocode:
- Comments describing steps before coding
- Example:
  # ask user for name
  # say hello

------------------------------
🔹 DATA TYPES
------------------------------
str   → text
int   → whole numbers (1, 2, -3)
float → decimals (1.5, 3.14)

IMPORTANT:
input() ALWAYS returns a STRING

Convert types:
x = int(input("x: "))
y = float(input("y: "))

------------------------------
🔹 MATH OPERATORS
------------------------------
+   addition
-   subtraction
*   multiplication
/   division
%   remainder (modulo)
**  exponent (power)

Example:
x ** 2 → x squared

------------------------------
🔹 INTERACTIVE MODE
------------------------------
Run:
python

- Executes code line by line
- Acts like a calculator
- Not used for full programs

------------------------------
🔹 USER-DEFINED FUNCTIONS
------------------------------
Define with def:

def hello(to):
    print("Hello,", to)

- def = define
- Parameters go in ()
- Indentation is REQUIRED

Call function:
hello(name)

------------------------------
🔹 DEFAULT PARAMETERS
------------------------------
def hello(to="world"):
    print("Hello,", to)

- Used if no argument is passed
- Optional arguments

------------------------------
🔹 RETURN VALUES
------------------------------
Functions can return values

Example:
def square(n):
    return n * n

- return sends value back
- stops function execution

------------------------------
🔹 SCOPE (VERY IMPORTANT)
------------------------------
- Variables exist ONLY inside their function
- Variables from main() NOT visible in other functions
- Pass values via parameters

------------------------------
🔹 MAIN FUNCTION PATTERN
------------------------------
def main():
    name = input("Name: ")
    hello(name)

def hello(to):
    print("Hello,", to)

main()

- Functions must be defined BEFORE use
- main() is explicitly called
- Clean program structure

==============================
1) TERMINAL & VS CODE COMMANDS
==============================

🔹 Creating & opening files
code hello.py
- Creates a file
- Opens it in VS Code editor

🔹 Running Python programs
python hello.py
- Runs file top → bottom
- Executes Python code

🔹 Clearing terminal
clear
Ctrl + L
- Clears screen (does NOT delete files)

🔹 Listing files
ls
- Shows files & folders in current directory

🔹 Copy file
cp hello.py goodbye.py
- Copies file
- No output = success

🔹 Rename / move file
mv goodbye.py farewell.py
mv file.py ../
- Rename or move file
- ".." = parent directory

🔹 Delete file
rm file.py
- Permanently deletes
- Often asks confirmation

🔹 Create folder
mkdir folder
- Creates directory

🔹 Change directory
cd folder
cd ..
cd
- Enter folder
- Go to parent folder
- Go to home directory

🔹 Delete folder
rmdir folder
- Folder must be empty

🔹 Productivity tips
↑ / ↓ arrows → command history
Tab → autocomplete filenames

==============================
2) STRING METHODS (CLEANING DATA)
==============================

Strings often contain:
- extra spaces
- bad capitalization
- messy formatting

🔹 Common string methods
(show is a string variable)

show.strip()
- Removes spaces from left & right

show.capitalize()
- Capitalizes ONLY first character

show.title()
- Capitalizes EVERY word (titles)

🔹 Chaining methods (VERY IMPORTANT)
show.strip().title()

Order matters:
1️⃣ strip → clean spaces
2️⃣ title → format text

🔹 Example
Input:
"  avatar the last airbender  "

Output:
"Avatar The Last Airbender"

==============================
3) LISTS + STRING JOIN
==============================

🔹 Creating new list
cleaned_shows = []

🔹 Adding items
cleaned_shows.append(show.strip().title())

🔹 Problem:
Printing list directly shows Python syntax:
['Show One', 'Show Two']

🔹 Solution: join()

" ".join(cleaned_shows)
", ".join(cleaned_shows)

- join() is a STRING method
- Takes a LIST as input
- String before .join() is the separator

🔹 Example
", ".join(["A", "B", "C"])
→ "A, B, C"

==============================
4) FUNCTIONS & SIDE EFFECTS
==============================

🔹 Side effect = something changes
NOT a return value

Common side effects:
- Printing to terminal
- Changing global variables
- Writing files

🔹 Example: printing
def say(phrase):
    print(phrase)

- Output appears immediately
- Nothing is returned

🔹 Global variables & side effects
emoticon = ":("

def main():
    global emoticon
    emoticon = ":)"
    say("Hi")

- global keyword required to MODIFY global variable
- Without global → Python blocks change

⚠️ Warning:
Too many side effects = hard to debug

==============================
5) RETURN VALUES (VERY IMPORTANT)
==============================

🔹 Difference
print() → side effect
return → gives value back to program

🔹 Example
def greet(text):
    if "hello" in text:
        return "hello, there"
    else:
        return "I'm not sure"

Nothing prints unless YOU print it.

🔹 Using return values
response = greet("hello computer")
print(response)

🔹 Why return is powerful
- Can store result
- Modify later
- Combine with other logic

Example:
print("Hm,", greet("hello"))

==============================
6) VARIABLES & TYPES
==============================

🔹 Variable = container for value
guess = 10

- "=" means assignment
- Right → left

🔹 input() always returns STRING
guess = input("Enter guess: ")

"50" ≠ 50

🔹 Converting types
int("50") → 50
float("3.14") → 3.14

🔹 Bug example
if guess == 50: ❌ (string vs int)

Fix:
guess = int(input("Enter guess: "))

==============================
7) VARIABLE SCOPE
==============================

🔹 Scope = where variable exists

def get_guess():
    guess = int(input())
    return guess

def main():
    guess = get_guess()
    print(guess)

- Same variable name ≠ same variable
- Each function has its OWN scope
- Values passed via return & arguments

==============================
8) DEFINING YOUR OWN FUNCTIONS
==============================

🔹 Syntax
def function_name(parameters):
    code here

🔹 Functions must be:
1️⃣ Defined
2️⃣ Then called

def main():
    print("Hi")

main()   ← REQUIRED

🔹 Why main()
- Clean structure
- Top-down logic
- Functions reusable

==============================
9) KEY TAKEAWAYS FROM SHORTS
==============================

✔ input() → always string

✔ strip + title = clean user data  
✔ Side effects ≠ return values  
✔ return gives control & flexibility

✔ Terminal = powerful, not scary  
✔ Functions + variables = building blocks
